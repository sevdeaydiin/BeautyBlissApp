## Beauty Bliss App 💄

Beauty Bliss is your go-to mobile application for discovering the latest and trendiest cosmetics every day. With a sleek design and user-friendly interface, it transforms your beauty shopping experience into something delightful. Whether you're browsing, saving favorites, or managing your profile, Beauty Bliss ensures a seamless experience for beauty enthusiasts.

## ✨ Features
- **Latest Cosmetics**: Discover the most popular and trending beauty products daily.
- **Seamless Login & Sign-Up:** Quickly access your account via Google or Facebook login.
- **Search & Filter:** Explore products by categories like Powder, Foundation, and Lipsticks.
- **Detailed Product Pages:** View star ratings, reviews, and pricing for each product.
- **Favorites:** Save products you love for quick access later.
- **Personalized Profile:** Manage your account, wishlist, address, and more from the profile section.

## 🛠️ Technologies Used
  **Frontend:**
  - **SwiftUI:** For building a modern, declarative user interface.
  - **UIKit:** For seamlessly integrating legacy views and advanced UI components.
  - **Kingfisher:** For efficient image loading and caching.

  **Backend**
  - **Node.js:** A scalable backend to handle API requests and user data.
  - **Postman:** For testing and verifying API endpoints during development.

## 📂 Project Structure
- **Views:** Contains all the UI components structured for reusability and clarity.
- **ViewModels:** Implements the MVVM pattern, bridging Views and Models.
- **Models:** Defines the data structure for the application.
- **Services:** Includes network layers for API communication.
